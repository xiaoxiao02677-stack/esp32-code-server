## 技术方案

### 1. SM2 加密登录
- 后端使用 BouncyCastle 的 SM2 实现（C1C3C2 模式）
- 前端使用 sm-crypto 库
- Python 使用 gmssl 库实现兼容加密

### 2. 验证码识别
- 使用 ddddocr 库进行 OCR 识别
- 验证码为 5 位字符图形验证码

### 3. 测试框架
- Python + requests 发送 HTTP 请求
- 自动化登录流程
- 生成 Markdown 报告 + CSV 报表
