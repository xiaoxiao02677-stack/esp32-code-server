## 1. 需求解读

原话：「LVGL 也按照 small_secreen 固件源码来，从开机就开始改变，不使用 yuhe 原生态。」

拆成三条可验收的：

| # | 要求 | 落点 |
|---|---|---|
| R1 | 界面按 `small_secreen` 的 my-s3-tft 皮肤来 | 布局/配色/交互与 `round_screen_display.cc` 逐项对齐 |
| R2 | **从开机第一帧**就变 | `SetupUI()` 第一件事就是品牌开机画面，原生 UI 一帧不出现 |
| R3 | 不使用 yuhe 原生态 | 状态栏图标、机器人 AI logo、`GetUserAgent()` 机型版本串全部不出现 |

## 2. 架构：一份皮肤，四个版型

原先只有 `yh-n16r8-st7789` 自带一份圆屏皮肤（`round_screen_display.cc` + 578KB `good_bg.c`）。
若给 154 / cam / big 各复制一份，会有 4 份布局代码 + 4 份背景像素。改为共享层：

```
main/display/yh_skin/
├── yh_skin_types.h       几何画像 YhSkinProfile + 字体集合 YhSkinFonts + 背景图符号
├── yh_skin_display.h/.cc 主界面 + 协议钩子 + 按键三事件 + 1s 节拍 + 壁纸
├── yh_skin_boot.h/.cc    开机画面（品牌名/副标题/呼吸点/版本/状态行/进度条）
├── yh_skin_cards.h/.cc   系统态卡片（配网/激活码/升级/错误）
└── yh_skin_assets.c      240×240 RGB565 背景图（yh_skin_bg，脚本生成，仅一份）
```

`YhSkinProfile` 三个画像：

| 版型 | 屏幕 | 画像 | 电池 |
|---|---|---|---|
| `yh-154tft-wifi` | 240×240 圆屏 | `Round240(true)` | 有（ADC8 + 充电检测） |
| `yh-n16r8-st7789` | 240×240 圆屏 | `Round240(false)` | 无（电量行隐藏） |
| `yh-cam` | 320×240 / 240×320 | `Wide320x240()` / `Tall240x320()` | 有 |
| `yh-big-ili9341` | 320×240 | `Wide320x240()` | 有 |

坐标全部 `profile.scaled(基准值)` 推导，240 屏上与原稿逐像素一致。

## 3. 「从开机开始」怎么做到的

时间线：

1. `Application::Initialize()` → `display->SetupUI()`
2. 皮肤 `SetupUI()` **只调 `Display::SetupUI()`**（跳过 `LcdDisplay::SetupUI` 的原生布局），
   立刻建主界面 + 盖一层**不透明**开机画面（深紫渐变 + good.jpg 60% + 「小柚」+
   「AI 陪伴助手」+ 三点呼吸动画 + 右下版本号）
3. 连 Wi-Fi / 激活期间：状态行写在开机画面底部，卡片盖在开机画面之上
4. 首次进待机（顶部出现 `HH:MM`，或收到第一条真实对话）→ 300ms 淡出交还主界面

配套的三个「防原生态泄漏」动作：

- **丢弃 UA 串**：`Application::Initialize()` 会把 `SystemInfo::GetUserAgent()` 当 system 消息
  写进消息区。皮肤侧的 `LooksLikeUserAgent()` 直接丢弃并记日志 `Drop native user-agent banner`。
- **吞掉开机噪声**：`SplashAbsorbsStatus()` 拦截「待机/初始化/正在连接…」这类文案，
  不让它们盖住品牌画面。
- **不建原生控件**：`top_bar_` / 原生状态栏 / 机器人 `emoji_label_` 一律不创建；
  只有基类必需的占位对象建成 1×1 隐藏（否则 `SetTheme` 会 null 解引用）。

## 4. 相对基准的差异（只有 3 处，其余 1:1）

| 差异 | 为什么 |
|---|---|
| 几何参数化 | 四个版型分辨率不同；240 屏下取值与原稿完全相同 |
| 开机首帧接管 | 基准是「进 SetupUI 直接出主界面」，没有开机画面 |
| 系统态卡片 | 基准把配网 SSID、6 位激活码、升级百分比塞进 200×50 气泡，240 圆屏读不清 |

保持不变：时间 y=10、电量 y=28、表情 120×120 居中 -15、气泡 200×50 距底 -55（文字宽 180 /
圆角 16 / 粉边 #FF7AA2）、底部提示（圆屏 y=-18，基准 -12 贴圆弧会被裁）、
good.jpg 背景 + 深紫渐变兜底、配色 6 值、彩蛋 5 组、23:30 / 07:00 自动问候、1s 节拍。

## 7. 你要做的一步

```bash
cd hardware/sets
python build.py      # 选版型 → 同步 → 注册 → 编译 → 归档
python flash.py      # 逐段烧录 + 回读校验 + 启动检查
```

换版型后**必须删 `<FW>/build` 全量重编**（旧 build 会残留上一版型的 board 宏）。

上电后照 `hardware/sets/UI_SKIN.md` 第 8 节的 10 项清单验收，重点看前三条：

1. 背光一亮就是「小柚」开机画面，没有状态栏、没有机器人 logo；
2. 三个呼吸点在动，右下角版本号与 `ai_ota.version` 一致；
3. 进待机后淡出，顶部 `HH:MM`、中心表情、底部「我在呢」。

## 8. 已知边界

- `yh-cam` 的摄像头预览链路未改动；皮肤只接管主界面与系统态，预览走 `SetPreviewImage`
  （`preview_image_` 已建成隐藏对象，基类路径不变）。真机需确认预览图不会被气泡遮挡。
- `yh-big-ili9341` 引脚仍是**未验证**状态（`pins_verified: false`），本次不涉及引脚结论。
- `yh-154tft-wifi` **没有**加双击彩蛋：该板 `Button` 用默认 `long_press_time`，
  加双击会改变单击手感，稳定性优先。
- 动画（呼吸点、淡出、进度条）都由 `lv_anim` 驱动，不新增 `lv_timer`，不额外吃 LVGL 节拍。
