# ESP32-S3 板子信息总结

## 1. 主控与硬件平台

| 项目 | 信息 |
|---|---|
| 芯片 | ESP32-S3 QFN56，revision v0.2 |
| 核心 | 双核 240MHz + LP Core |
| 无线 | Wi-Fi + Bluetooth 5 LE |
| PSRAM | 8MB Octal SPI，AP_3v3 |
| Flash | 16MB，3.3V，Quad mode |
| 晶振 | 40MHz |
| MAC | `b8:1f:3f:c3:96:20` |
| 连接端口 | COM10，USB-Serial/JTAG |
| ESP-IDF 工具版本 | **v6.1** |

## 2. 已识别外设

| 外设 | 型号/类型 | 接口 | 状态 |
|---|---|---|---|
| 音频编解码器 | ES8311 | I2S | 已识别 |
| 显示屏 | ILI9341，2.8 寸 | SPI | 已识别 |
| 触摸屏 | 型号未确定 | I2C | 存在但初始化失败：`touch ic error!` |
| SD 卡 | 未定 | SPI | 已识别，固件有 SD 测试 |
| 固件备份 | `full_fw.bin` | 64KB 应用分区/片段 | 已备份 |

## 3. 引脚配置参考

以下来自固件字符串和典型配置推断，**不是原理图级确认**：

| 外设 | 参考引脚 |
|---|---|
| ES8311 I2S | BCLK=GPIO46，WS=GPIO45，DIN=GPIO7，MCLK=GPIO2 |
| ILI9341 SPI | CS=GPIO5，DC=GPIO6，RST=GPIO4，MOSI=GPIO7，SCK=GPIO6，MISO=GPIO1 |
| 触摸 I2C | SDA=GPIO1/8，SCL=GPIO2/9，需确认 |
| SD 卡 SPI | CS=GPIO4，MOSI=GPIO7，MISO=GPIO1，SCK=GPIO6 |

## 5. 关键结论

- 这是一块 **ESP32-S3 + 8MB PSRAM + 16MB Flash** 的音频/显示型开发板。
- 板载 **ES8311 音频编解码器**、**ILI9341 2.8 寸 SPI LCD**、**SD 卡槽**，并疑似有 **I2C 触摸屏**。
- 固件中已发现 `es8311`、`ILI9341`、`SD card Test OK`、`touch ic error` 等关键字符串。
- 开发环境已记录为 **ESP-IDF v6.1**。
- 主控、存储、无线和外设型号可信度较高；**精确 GPIO 引脚可信度较低**，因为固件无调试符号，且多处引脚存在冲突，例如 GPIO6 同时被列为 LCD DC/SCK，GPIO7 同时被列为 I2S DIN、LCD MOSI、SD MOSI。
- 如需精确接线，建议：读取完整 16MB Flash、解析分区表和 NVS、获取开发板型号或原理图，并使用 ESP-IDF v6.1 重新构建/验证固件。

## 6. 一句话总结

已确认是一块带 ES8311 音频、ILI9341 SPI 屏、SD 卡和 I2C 触摸的 ESP32-S3 开发板，固件外设信息已提取，开发环境为 ESP-IDF v6.1，但精确引脚定义仍需完整固件或原理图验证。
