## 一、项目概述

本项目为大屏语音助手 ESP32 固件，基于 xiaozhi-esp32 框架二次开发。核心功能包括：
- WiFi/4G 双网络接入
- 唤醒词语音交互（"小智小智"）
- LLM 对话（支持多模型提供商）
- TTS 语音播报
- 大尺寸 TFT 彩屏显示（240x240）
- BOOT 键三事件交互（短按/双击/长按）

## 四、状态机定义

### 4.1 状态枚举（`device_state.h`）

```cpp
enum DeviceState {
    kDeviceStateUnknown,        // 未知
    kDeviceStateStarting,       // 启动中
    kDeviceStateWifiConfiguring, // 配网中
    kDeviceStateIdle,           // 空闲
    kDeviceStateConnecting,     // 连接中
    kDeviceStateListening,      // 监听中
    kDeviceStateSpeaking,       // 说话中
    kDeviceStateNotifying,      // 通知中
    kDeviceStateUpgrading,      // 升级中
    kDeviceStateActivating,     // 激活中
    kDeviceStateAudioTesting,   // 音频测试中
    kDeviceStateFatalError      // 致命错误
};
```

### 4.2 状态转换规则（`device_state_machine.cc`）

| 当前状态 | 可转换至 |
|---------|---------|
| Starting | WifiConfiguring, Activating |
| WifiConfiguring | Activating, AudioTesting |
| AudioTesting | WifiConfiguring |
| Activating | Idle, Upgrading, WifiConfiguring |
| Idle | Connecting, Listening, Speaking, Notifying, Activating, Upgrading, WifiConfiguring |
| Connecting | Listening, Speaking, Idle |
| Listening | Speaking, Idle, Connecting |
| Speaking | Idle, Listening, Notifying |
| Notifying | Idle |
| Upgrading | Idle, Activating |
| **FatalError** | **无（永久卡死）** ⚠️ |

## 五、交互逻辑

### 5.1 BOOT 键三事件

| 事件 | 触发条件 | Idle 状态行为 | Speaking/Listening 状态行为 | Starting 状态行为 |
|------|---------|--------------|---------------------------|------------------|
| 短按 | < 180ms | ToggleChatState（开始/结束对话） | AbortSpeaking（打断） | EnterWifiConfigMode（配网） |
| 双击 | 180ms < 间隔 < 400ms | NextEasterEgg（表情彩蛋） | 无效 | 无效 |
| 长按 | ≥ 1000ms | MuteToggle（静音切换） | AbortSpeaking（取消） | EnterWifiConfigMode（前 30s 有效） |

### 5.2 唤醒词流程

```
Idle → 检测到唤醒词 → kDeviceStateActivating → 连接服务器 → kDeviceStateListening
                                                  ↓
                    kDeviceStateSpeaking ← 服务器返回音频 ← LLM 生成回复
                          ↓
                    AbortSpeaking（打断）→ kDeviceStateListening
                          ↓
                    音频播放完毕 → kDeviceStateIdle
```

### 5.3 监听模式（Listening Mode）

| 模式 | 行为 |
|------|------|
| `kListeningModeAutoStop` | 检测到用户说话结束自动停止监听 |
| `kListeningModeManualStop` | 需用户按键手动停止 |
| `kListeningModeRealtime` | 持续监听，不自动停止 |

## 六、UI 显示系统

### 6.1 显示驱动层级

```
Application::SetStatus/SetEmotion/SetChatMessage
        ↓
    Display（基类接口）
        ↓
    BigscreenDisplay（板级实现）← 实际使用
        ↓
    LvglDisplay（LVGL 封装）
        ↓
    SpiLcdDisplay（底层 SPI 驱动）
```

### 编译环境说明（重要）

`esp_video 2.5.0`（registry 最新版）的 esp_h264 依赖带 `$CONFIG{...} == False` matches，esp32s3 上该 Kconfig 变量未定义，组件管理器"新版本检查"求值抛错导致 configure FATAL。**修复**：构建脚本已加 `IDF_COMPONENT_CHECK_NEW_VERSION=0`（build-bigscreen.bat / build_verify_bigscreen.bat）。此为环境级开关，不影响 lock 锁定的组件版本。若未来 esp_video 修复该 manifest，可移除。
