# 用户管理模块需求文档（整合版）—— 测试环境

> 来源：用户需求 2026-10-14。实施范围：P0 全部 + P1 核心（批量导入导出、字段级展示配置、自定义模型/音色审核、配额、审计）。
> 环境：sandyun.top（SSH 22223），前端 8101（/var/www/console-v2），后端 8002 manager-api，MySQL xiaozhi_esp32_server（root/123456），Redis。
> 本地源码：console-v2（前端）、code-server-mirror/manager-api（后端，与服务器 md5 一致）。

## 一、模块定位
面向多用户 / 多租户的 AI 能力管理模块。管理员统一配置用户、权限、展示项、默认模型与资源策略；用户仅能在授权范围内使用和自定义 LLM、音色等资源。

## 二、角色与权限体系
- 角色：超级管理员 / 管理员 / 普通用户 / 只读访客
- 权限粒度：菜单、按钮、数据、模型、音色、API Key、额度
- 鉴权：前端路由守卫 + 后端接口鉴权 + Token 携带权限声明；越权 403 并记录日志
- 权限变更实时生效

## 三、管理员端
1. 用户管理：自定义添加、邀请、批量导入/导出、启用/禁用/锁定/软删除/恢复、批量操作、分组标签、首次登录强制改密、密码重置与过期策略、会话管理与强制下线
2. 权限管理：RBAC + 权限点、角色模板、权限复制、变更二次确认与影响范围展示、变更实时生效、审计日志
3. 展示项配置：字段级权限（可见/可编辑/只读/隐藏）、配置模板（默认/VIP/企业）、继承与覆盖（系统默认→角色默认→用户自定义）
4. 默认模型与资源：默认音色/LLM、参数模板（温度/TopP/额度）、平台/角色/用户三级默认、冲突策略（可覆盖/锁定）
5. 模型与音色管理：状态（可用/维护/下线）、可见性（公开/组织/私有）、配额限流、用量计费、降级回退
6. 安全审计：密码强度、验证码、敏感操作二次确认、登录/操作/权限变更/模型调用日志、管理员操作不可篡改
7. 运营体验：搜索筛选排序分页、仪表盘、用户详情页（信息/权限/默认模型/展示项/审计）、批量操作、通知机制

## 四、用户端
1. 基础：不可切回管理端（前端隐藏+路由拦截+后端鉴权+403）、个人资料、用量查看（Token/调用次数/剩余额度）、申请权限
2. 自定义模型与音色：权限控制、审核机制、密钥加密存储不可明文返回、额度限制、健康检查、仅本人可见
3. 展示与空状态：模型/音色为 0 不展示选择列表、空状态引导、冲突按管理员策略展示

## 五、关键边界
- 模型数量 0：用户端不展示；管理员端可配置但提示「暂无可用模型」
- 自定义 LLM/音色：校验权限/密钥/额度/审核状态；密钥加密存储
- 权限变更实时生效
- 删除用户软删除 + 审计保留 + 可恢复
- 前端隔离是体验，后端隔离是安全边界

## 六、数据模型（新增表）
sys_role、sys_user_role、sys_permission、sys_role_permission、sys_audit_log、sys_display_config、sys_user_default（默认模型音色）、sys_user_custom_model、sys_user_custom_voice、配额字段

## 七、优先级
- P0：权限校验与越权拦截；用户启用/禁用/软删除；默认模型音色配置；模型 0 展示规则；审计日志；用户端不可进管理端
- P1：批量导入导出；分组标签；字段级展示权限；自定义模型/音色审核；配额限流；会话管理
- P2：SSO、多租户、计费、高级分析、健康检查自动降级（本期不做）

## 八、验收清单
- [ ] 管理员可添加、禁用、删除、恢复用户
- [ ] 管理员可修改用户权限等级
- [ ] 权限变更后后端接口同步生效
- [ ] 管理员可配置用户可修改的展示项
- [ ] 管理员可配置默认 LLM、音色
- [ ] 模型数量为 0 时，用户端不展示模型
- [ ] 用户端无法切回管理端
- [ ] 用户端越权请求返回 403
- [ ] 用户可自定义添加 LLM、音色
- [ ] 自定义模型/音色支持审核、加密、配额
- [ ] 所有敏感操作有审计日志
- [ ] 空状态、错误提示、降级策略完整
