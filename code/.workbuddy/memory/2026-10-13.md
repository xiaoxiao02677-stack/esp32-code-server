- 将 demo.html（ESP32浏览器烧录工具）部署到 /var/www/console-v2/firmware-flash/
- nginx配置添加 /firmware-flash/ 路由
- 访问地址：https://sandyun.top:8101/firmware-flash/

### 功能说明
- 基于 Chrome Web Serial API，直接在浏览器里给 ESP32 烧录固件
- 无需安装任何软件，支持 Chrome 89+ / Edge 89+
- 需要 HTTPS 或 localhost 环境（Web Serial API 安全要求）

### 测试环境特点
- 使用自签名证书，Chrome 会提示不安全，需手动确认
- 连接 USB 串口后，点击「连接串口」选择 ESP32 设备
- 支持 115200/230400/460800/921600 波特率
- 自动猜测常见 .bin 文件的烧录地址
