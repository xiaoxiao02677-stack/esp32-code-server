### 根因（按贡献度）
1. **服务死了 6.5h 无人管**（P0）：systemd `Restart=on-failure` 对**退出码 0** 不生效，而 app.py 收到 SIGTERM 后走 `wait_for_exit()` 正常返回 → exit 0。2026-10-08 20:06 退出后一直没起来。→ 改 `Restart=always`（实测 kill -9 后 12s 自动拉起）。

3. **端到端零心跳**（P1）：服务端 `ping_interval=None` + `enable_websocket_ping=false`；固件同样零心跳（sdkconfig 里 KEEPALIVE 0 次，从不发 ping）。→ 改 `ping_interval=30 / ping_timeout=60`。**安全性已交叉验证**：固件 `web_socket.cc:392` 收到 Ping(0x9) 自动回 Pong(0xA)，无需改固件。
