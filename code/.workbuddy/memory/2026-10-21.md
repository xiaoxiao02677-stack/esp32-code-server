## 23:xx 任务G：#main-content 内容看不到 → A10 容器滚动从未生效（已修）

### 根因（浏览器实测决定性证据）
`.app-shell` 是 `display:flex`（默认 `align-items:stretch`）+ 固定 `height:100dvh`，
把唯一子项 `.app-canvas` 沿交叉轴**钉死在视口高**。canvas 内容超出后被自身 `overflow:hidden`
（28px 圆角裁切用）直接裁掉；shell 的 `overflow-y:auto` 因 scrollH==clientH 永远滚不动。
注入 3000px 实测：canvas clientH 848 / scrollH 3651（2739px 被裁），shell 滚动增量 0。
**A10「shell 容器滚动」架构自上线以来实际从未生效**，视口装得下时无症状，列表数据多即复现。

### 修复（global.css .app-canvas，不碰任何 overflow 规则）
```css
align-self: flex-start;              /* 不被 stretch，按内容自然增高，shell 接管滚动 */
min-height: calc(100vh - 52px);      /* 短内容满屏卡片视觉保持（52px=shell 上下 padding） */
min-height: calc(100dvh - 52px);
```
上一任务文档红线「.app-canvas 的 overflow 规则不得修改」——本次未改 overflow:hidden，
只加 align-self + min-height，与红线不冲突。
