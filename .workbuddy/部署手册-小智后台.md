## 常用运维命令

```bash
systemctl status yuhe-server        # 查看状态
systemctl restart yuhe-server       # 重启（FunASR 加载约 40 秒）
journalctl -u xiaozhi-manager-api -f   # 跟踪 Java 日志
tail -f /root/xiaozhi-server/main/yuhe-server/data/app.log
```

## 代码更新流程（改完本地源码后）

1. 打包改动文件，上传到 `/root/xiaozhi-server` 对应位置：
   `python .workbuddy/remote_ssh.py put <本地文件> /root/xiaozhi-server/<路径>`（Git Bash 加 `MSYS_NO_PATHCONV=1`）
2. Python 服务：`systemctl restart yuhe-server`
3. Java 服务：`cd /root/xiaozhi-server/main/manager-api && mvn clean package -Dmaven.test.skip=true` → `cp target/xiaozhi-esp32-api.jar /opt/xiaozhi/` → `systemctl restart xiaozhi-manager-api`
4. 前端：`cd /root/xiaozhi-server/main/manager-web && npm run build` → `cp -r dist/* /var/www/xiaozhi-manager/` → `systemctl reload nginx`

## 网络接入方案（二选一）

**方案 A：ESP32 与服务器同局域网（推荐，当前配置即用）**
- WebSocket：`ws://192.168.50.4:8000/yuhe/v1/`
- OTA：`http://192.168.50.4:8003/yuhe/ota/`

**方案 B：外网访问（需路由器配置）**
- 登录路由器管理页（192.168.50.1）→ 端口映射/虚拟服务器，添加：8000、8001、8002、8003 → 192.168.50.4
- 之后用 `ws://223.247.29.147:8000/yuhe/v1/`（公网 IP 可能随运营商变化，可用 sandyun.top 域名）
- 注意：IPv6 AAAA 记录指向网关而非本机，如需 IPv6 需在 VM 上配 DHCPv6 或改 AAAA 指向 VM 地址
