### 3.3 WS UDP 心跳 8002

```
ss -lunp | grep 8002
    UNCONN 0 0  0.0.0.0:8002  0.0.0.0:*  users:(("python",pid=568605,fd=21))
启动日志： [core.heartbeat]-INFO-WebSocket UDP心跳已启动   0.0.0.0:8002
配置读出： server.ws_udp_heartbeat_port = 8002（read_config_from_api=True 下仍生效）
```

回环实测：

| 来源 | 结果 |
|---|---|
| `127.0.0.1:8002` | ✅ rtt 4.5ms，回包 `{"type":"udp_heartbeat_ack"}` |
| `192.168.50.10:8002`（LAN） | ✅ rtt 0.8ms，同上 |
| `sandyun.top:8002`（公网） | ⚠️ 超时 |

- 公网 UDP 未转发是**基础设施层**问题：路由器只做了 TCP 端口映射；同机既有的 `12399/UDP` 公网同样不可达（其 TCP 端口可达）。
- **固件侧为 fire-and-forget**：`websocket_protocol.cc:366` 对回包仅 `ESP_LOGD` 打日志，注释「可扩展为配置同步」，`OpenUdpChannel()` 在 WS 建链后无条件调用。故服务端监听已到位即为对接完成，设备功能不受影响。
- 若需真机公网回环：在出口路由器为生产 VM 追加 `UDP 8002 → 192.168.50.10:8002` 映射即可，无需改固件。

### 3.4 动态字形推送 glyph_push

真机 WS 链路（`ws://127.0.0.1:8000/yuhe/v1/` 与经 nginx 的 `ws://sandyun.top:8001/yuhe/v1/` 均验）：

```
hello: features.glyph_push=true, text_font={bundle:noto-v1, charset:basic, size:20, bpp:4}
listen/detect "你好小禾，请用一句话介绍你自己"
  <- type=stt text='你好小禾，请用一句话介绍你自己' glyph_push=YES
     固件校验 PASS | glyphs=7  | U+5C0F U+79BE U+53E5 U+4ECB U+7ECD U+81EA U+5DF1
  <- type=tts state=sentence_start text='主人，小智现在有点忙' glyph_push=YES
     固件校验 PASS | glyphs=5  | U+4E3B U+4EBA U+5C0F U+667A U+5FD9
  <- type=tts state=sentence_start text='我们稍后再试吧' glyph_push=YES
     固件校验 PASS | glyphs=2  | U+4EEC U+5427
统计：文本消息=3 含 glyph_push=3 二进制音频帧=71 固件校验失败=0
```

| 用例 | 结果 |
|---|---|
| 正向 `charset=basic`（真实四版型默认档） | ✅ 3/3 文本消息带字模，固件校验全 PASS，语音帧无异常 |
| 负向 `--no-glyph`（不声明能力） | ✅ 0/3 带字模（零开销、零回归） |
| `charset=common` + 常用字 | ✅ 0 字模（设备本就具备，正确跳过） |
| `charset=common` + 生僻字 `𠮷`(U+20BB7) | ✅ 命中 1 字模，固件校验 PASS（与厂商 README 示例一致） |
| 经 nginx 8001 真实链路 | ✅ 同上 PASS |
| 服务端日志 | `客户端字形补字能力: bundle=noto-v1, charset=basic, 20_4` → `字形补字已就绪: noto-v1, 字符集=['basic','common'], 档位=[(14,1),(16,4),(20,4),(30,4)]` → `已附带字形推送: 7 字` |
| 上限保护 | 提取器硬限 64 字 / 64KiB，超限即截断（厂商实现内置） |

**固件等价校验器**复刻了 `text_glyph_payload.cc::Parse()` 的全部拒绝规则：`v==1`、`bundle`/`size`/`bpp` 与设备能力**完全相等**、`glyphs` 数组 ≤64、`codepoint∈(0,0x10FFFF]`、`adv_w∈[0,2^32)`、`box_w/box_h∈[0,64]`、`ofs_x/ofs_y∈int16`、base64 解码长度严格等于 `ceil(w*h*bpp/8)`、累计 bitmap ≤64KiB。实测全部通过。

> 📌 观察（非缺陷）：四版型内置字体为 `font_noto_sans_basic_20_4`、assets 未装 common 字库，设备上报 `charset=basic`（890 码位）→ **所有汉字都会被判为缺字并推送**，即该功能同时补齐了「小屏无法显示中文」的能力。单句中文（约 15 字）约 3KB 字模、base64 后约 4KB；如需降低带宽，可在 assets 内装 common 字库后设备自动改为 `charset=common`，此时只推生僻字。
