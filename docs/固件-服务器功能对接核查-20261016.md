## 结论与待办

### ❌ 未对接（5 项）
1. **配置版本检查** `GET /ota/config/version` —— 固件每次启动必调，目前稳定 404。需在 Java `OTAController` 补该端点（返回 `{version, download_url}`）。
2. **配置包下载** —— 依赖上一项，需一并提供配置文件服务。
3. **OTA 固件包升级** —— `ai_ota` 表为空，设备拿不到真实升级 URL。需在后台「固件升级管理」上传四版型固件包并绑定 board type。
4. **WS UDP 心跳（8002）** —— 固件写死 8002，服务端无 UDP 监听。无害冗余；启用需增 UDP 服务或改固件端口。
5. **动态字形推送 glyph_push** —— 固件具备且默认开启，服务端未实现生成/下发。可选增强。

### ⚠️ 部分对接 / 需注意（4 项）
1. **assets 资源包 OTA** —— 端点存在但无记录；`/xiaozhi/assets/download/*` 返回 401，需放行或改用带鉴权路径。
2. **唤醒词覆盖行为** —— 服务端下发设备级唤醒词后，编译期默认「你好小禾」失效（现存设备已下发 `["琳琳","玲玲","灵灵"]`、`["你好"]`）。
3. **唤醒词存储位置** —— `ai_agent_wake_word` 0 行，实际落在 `ai_device_config.wake_word`；两套入口并存，建议明确单一真源。
4. **固件副本与上游源码独立** —— `hardware/sets/xiaozhi-esp32` 与 `hardware/small_screen_camera/xiaozhi-esp32` 不同步。

### ⚪ 两端具备但未启用（3 项）
- MQTT 通道（`server.mqtt_gateway=null`）
- UDP 网关（`server.udp_gateway=null`）
- MCP 接入点（`server.mcp_endpoint=null`）
