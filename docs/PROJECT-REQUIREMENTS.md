# CC 控制台功能补全 · 需求说明（PRD）

> 版本：v1.0 · 生成日期：2026-10-07
> 配套文件：`PROJECT-HANDOFF.md`（运维交接手册）、`cc-console/src/App.vue`（当前实现）
> 目标：把用户提出的 4 条诉求转换为**可验收的具体功能需求（FR）**，每一项都锚定真实后端接口或明确标注待补接口。

---

## 0. 背景

当前 `/cc/`（部署于 `http://sandyun.top:8001/cc/`）是新建的可视化控制台，已接入原控制台核心功能，共 **16 个功能页 + 1 个 API 调试页**。用户提出 4 项诉求：

1. 把"没预留的功能"上线到 `/cc/`，MCP 等高级功能全部安排上线；
2. 模拟 ESP32 通信链路（ASR → LLM → TTS），因为 ESP32 硬件 TTS 不播放声音；
3. 所有 Web 控制台功能必须**真正控制后台数据**，不能只是纸老虎；
4. Web 控制台 UI 布局合理适配网页版。

---

## 1. 现状审计（真接 vs 只读）

下表基于 `cc-console/src/App.vue` 实际方法盘点。**"写能力"指调用了 POST/PUT/DELETE 并落库**。

| 页面 | 读（GET） | 写（CUD） | 是否纸老虎 |
|---|---|---|---|
| 智能体 agents | ✓ | 增/改/删（`/agent`、`/agent/{id}` PUT/DELETE）| 否 |
| 音色试听 voices | ✓ | 仅试听（无 CRUD）| 部分（试听是真接口，无管理）|
| 聊天记录 chat | ✓ | **无**（无删会话/发消息）| 是（只读）|
| 记忆管理 memory | ✓ | 增/删事实（`/memory/facts` POST/DELETE）| 部分（无编辑）|
| 知识库 knowledge | ✓ | 增/删库（`/datasets` POST/DELETE）| 否 |
| 模型管理 models | ✓ | 启停（`toggleModel`）| 否 |
| 设备管理 devices | ✓ | 仅绑定智能体（`/device/bind/{agentId}` POST）| 部分（无改名/解绑/重启/删除）|
| 系统参数 params | ✓ | 改（`/admin/params` PUT）| 否 |
| 用户管理 users | ✓ | 禁用/启用（`/admin/users/changeStatus` PUT）| 否 |
| 智能体模板 templates | ✓ | **无** | 是（只读列表）|
| OTA 固件 ota | ✓ | **无**（无上传）| 是（只读列表）|
| 数据字典 dicts | ✓ | **无**（无增项）| 是（只读）|
| 替换词 correctwords | ✓ | 增/改/删（`/correct-word/file` POST/PUT/DELETE）| 否 |
| 服务器节点 servers | ✓ | **无** | 是（只读）|
| API 调试 apis | ✓ | 任意原始请求（142 接口）| 否（兜底）|

**结论**：基础 16 页已全部接真实接口（无 `alert('去原控制台')` 占位桩）；**纸老虎集中在"只读页"和"设备/记忆的部分写能力缺失"**。这正是需求 3 的攻坚点。

## 3. 需求 R2：ESP32 链路模拟器（ASR → LLM → TTS 浏览器播放）

### 3.1 痛点
ESP32 真机硬件 TTS 不播放声音，无法在设备上验证"识别→理解→合成→出声"全链路。需在 Web 端用**浏览器扬声器**替代硬件扬声器，跑通同一条逻辑链路，便于调试与演示。

### 3.2 链路定义
```
[麦克风/音频] → ASR → 文本 → [LLM 对话] → 回复文本 → TTS → 音频 → 浏览器播放
```
对应真机 `core/connection.py` 流水线（ASR 消费 PCM → LLM → TTS 返回 opus）。

### 3.3 功能需求
- **FR-R2.1（页面）**：新增「链路模拟器」页（图标 🔗，分组"调试"），含三阶段可视化时间轴：ASR → LLM → TTS。
- **FR-R2.2（智能体选择）**：下拉选智能体（决定 LLM/TTS/ASR 配置）。
- **FR-R2.3（ASR 阶段）**，二选一，推荐 MVP 用 (a)：
  - **(a) 浏览器 ASR（MVP）**：用 Web Speech API（`webkitSpeechRecognition`）采集麦克风→文本，标注"浏览器识别（模拟 ASR）"，支持手动改文本。
  - **(b) 真实 ASR 端点（增强）**：新增 `xiaozhi-server` 端点 `POST /api/asr`（上传 wav/pcm → 走 `core.providers.asr` → 返回文本）。**当前无此端点，需后端新增**（见 §7）。
- **FR-R2.4（LLM 阶段）**：将 ASR 文本作为用户输入，调用智能体对话接口（复用聊天链路 `/agent/{id}/chat` 或等效），展示流式/完整回复文本；记录耗时。
- **FR-R2.5（TTS 阶段）**：将 LLM 回复文本送往 TTS 试听端点 `GET /api/tts/preview?voice={voice}&text={text}`（POST body 带完整 TTS config_json，由 manager-api 代理转发），拿到音频二进制后用 `<audio>` 在**浏览器播放**。
- **FR-R2.6（播放）**：TTS 音频必须在浏览器内可播放（这是本需求核心——替代硬件出声）；提供播放/下载按钮。
- **FR-R2.7（超时/错误）**：各阶段独立 loading 与错误提示（ASR 失败、LLM 超时、TTS 合成失败分别提示，不中断整链）。
- **FR-R2.8（日志）**：底部展示各阶段耗时、请求/响应摘要，便于对比真机表现。

### 3.4 关键约束
- TTS 试听端点已存在且返回可播放音频（`tts_preview_handler.py`，支持 wav/mp3/ogg/pcm/opus），**浏览器播放闭环已具备**，R2 主要工作量在 ASR 阶段与编排 UI。
- 文本上限 60 字（试听端点限制），模拟器需截断/提示。

**验收**：选智能体 → 说话或输入文本 → 看到 ASR 文本 → LLM 回复 → 点播放听到浏览器合成音；任一阶段失败有独立报错。

**验收**：对 §1 标"是/部分"的每一页，均能用 UI 完成至少一项真实落库写操作，并在后端（DB/设备）验证生效。

## 5. 需求 R4：Web 版 UI 布局适配

### 5.1 响应式
- **FR-R4.1** 断点适配：≥1200px 三栏（侧栏+内容+右详情）；768–1199px 两栏（侧栏可收起）；<768px 侧栏抽屉式（汉堡菜单）。
- **FR-R4.2** 表格/列表在窄屏改为卡片流，不横向滚动溢出。

### 5.2 导航与信息架构
- **FR-R4.3** 侧边栏分组：概览 / 智能体相关（智能体、模板、MCP）/ 内容（知识库、记忆、替换词）/ 音视（音色、聊天）/ 系统（设备、参数、用户、OTA、字典、服务器）/ 调试（API、链路模拟器）。
- **FR-R4.4** 顶部全局搜索/快捷跳转（可选）。
- **FR-R4.5** 当前页高亮 + 面包屑。

### 5.3 密度与可读性（网页版）
- **FR-R4.6** 默认宽松密度（行高、间距适配桌面），提供"紧凑模式"开关。
- **FR-R4.7** 长文本（系统提示词、替换词内容）用可折叠/模态编辑，不在列表撑爆。
- **FR-R4.8** 模态框最大宽度 640–760px、最大高度 86vh 滚动（现有 `.modal-card` 已具），全站统一。

### 5.4 主题
- **FR-R4.9** 保留现有 kawaii 粉紫主题，确保深浅色均可读（当前仅浅色，补深色可选）。

**验收**：在 1440 / 1024 / 375 三档视口下打开所有页，无横向滚动、无重叠、交互可达。

## 7. 风险与待确认项（阻塞需求落地）

1. **MCP 写接口缺失**：`AgentMcpAccessPointController` 只有 2 个 GET。若要"配置/生成"MCP，须后端补 `create/update/delete`。→ 需与后端确认是否要做写，或 R1 仅做只读展示。
2. **ASR 无独立 HTTP 端点**：R2 增强版需新增 `POST /api/asr`。MVP 用浏览器 Web Speech API 规避。
3. **设备写接口待确认**：改名/解绑/重启/删除的设备端 REST 端点需在 `DeviceController` 核实字段与路径。
4. **OTA/字典写接口**：当前仅列表 GET，上传/新增需后端补 `multipart` 与 `POST`。
5. **记忆编辑端点**：`PUT /memory/facts/{id}` 需确认是否存在。
6. **TTS 试听 60 字上限**：链路模拟器长文本需分段或提示。
7. **部署约束**：改 Web 走 `vite build` + rsync 到 `/var/www/cc-console`；改后端 Java 走 `mvn -DskipTests`；详见 `PROJECT-HANDOFF.md` 部署速查表。
