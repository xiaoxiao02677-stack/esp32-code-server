这套界面的设计要点：
要点说明
眼睛即全部没有嘴、没有身体。情绪全部由眼睛的形状 / 大小 / 倾角 / 辉光强度四个维度表达
眨眼转场切换表情时先闭眼再睁开，比直接变形自然得多，这是机器人脸的核心手法
★ 高光点这是「灯」和「眼睛」的分界线。主高光（上方偏右的小白椭圆）+ 次高光（下方偏左的反射光）。没有它，眼睛只是两颗 LED
★ 幼态布局眼睛更大（54×62）、位置更靠下（cy 126）、间距更开（80px）。大眼 + 低位 + 宽距 = 婴儿图式，这是可爱的底层原理
★ 眨眼挤压眨眼不是纯垂直压扁，而是横向同时拉伸 12%（squash & stretch），睁到底时过冲 6%。有弹性才活
辉光分层外晕（径向渐变到面板）→ 主体（中心白→边缘主色）→ 亮芯 → 高光。ESP32 上不要做高斯模糊，用尺寸递减 + 透明度递增模拟
黑色最省电IPS 上黑像素几乎不耗电，这套方案适合 24 小时常亮，续航远好于浅色界面
零位图所有眼睛形状都是参数化路径，flash 占用几乎为零，也不用 PSRAM 存图
真机实现：emopet_face.c 用 lv_canvas 直接画路径，眼睛参数放进一张表情表， 切换时启动 300ms 的闭眼→换形→睁眼动画。详见工程 README。
