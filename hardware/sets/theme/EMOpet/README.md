# EMOPET 风格 · 机器人脸屏 · ESP-IDF v6.1

240×240 **方形 IPS**（ST7789）· 黑底 + 蓝色发光眼 · ESP32-S3。
**眼睛即全部**：没有嘴、没有身体，所有情绪靠两只会发光的眼睛表达。

先打开 `docs/emopet_face_preview.html` 看效果（可交互：18 个表情、6 种眼色、自动演示）。

---

## 1. 设计要点

| 要点 | 说明 |
|---|---|
| **★ 高光点** | **这是「灯」和「眼睛」的分界线。** 主高光（上方偏右的小白椭圆）+ 次高光（下方偏左的反射光）。没有它，画出来只是两颗 LED |
| **★ 幼态布局** | 眼睛更大（54×62）、位置更靠下（cy 126）、间距更开（80px）。**大眼 + 低位 + 宽距 = 婴儿图式**，这是可爱的底层原理 |
| **★ 眨眼挤压** | 眨眼不是纯垂直压扁，而是**横向同时拉伸 12%**（squash & stretch），睁到底时过冲 6%。有弹性才活 |
| **眼睛即全部** | 情绪由 **形状 / 大小 / 倾角 / 辉光** 四个维度表达，无嘴无身体 |
| **眨眼转场** | 切换表情时先闭眼再睁开（300ms），比直接变形自然得多——这是机器人脸的核心手法 |
| **辉光分层** | 同一形状画 3 层（尺寸 1.00/0.90/0.78，透明度递增），**绝不用高斯模糊** |
| **黑色最省电** | IPS 上黑像素几乎不耗电，这套方案适合 24 小时常亮 |
| **零位图** | 所有形状都是参数化路径，flash 占用几乎为零，也不占 PSRAM 存图 |

### 可爱版圆眼的分层结构（`draw_cute_eye`）

```
① 外光晕   主色 @37%  尺寸 1.22×   → 柔光溢到黑色面板上（EMOPET 质感来源）
② 主体     主色 @100% 尺寸 1.00×   → 胶囊形，圆角 = 短边一半
③ 亮芯     主色→白混合 尺寸 0.74×  → 偏上 5%，发光体的正确结构
④ 主高光   纯白 @90%  尺寸 0.38×   → 上方偏右（cx+0.17w, cy-0.29h）★关键
⑤ 次高光   纯白 @50%  尺寸 0.21×   → 下方偏左，增加球面湿润感
```

### 眼睛形状

| 形状 | 用在哪 | 画法 |
|---|---|---|
| `EM_DOT` | 待机 / 聆听 / 说话 / 惊讶 / 生气 | 圆角矩形（圆角 = 短边一半）+ 近白小芯 |
| `EM_ARC` | 开心 `∩∩` / 难过 `∪∪` / 困 `——` | 二次贝塞尔采样成折线，描粗线 |
| `EM_HEART` | 爱心 | 6 点多边形 |
| `EM_STAR` | 星星眼 | 10 点五角星 |
| `EM_SPIRAL` | 晕 `@_@` | 螺旋折线描边 |
| `EM_X` | 断线 / 死机 | 两条交叉粗线 |
| `EM_QR` | 配网 | 整屏二维码（占位，接 `espressif/qrcode` 可换真实码） |

### 18 个表情

`待机 聆听 说话 开心 爱心 困 难过 惊讶 生气 眨眼(wink) 星星眼 晕 思考 害羞 断线 低电量 开机 配网`

`wink` 是**左右眼不同形状**的实例：左眼 `dot`、右眼笑弧。覆盖机制在 `R_OVER[]` 表里，照这个格式可以加任意不对称表情。

## 4. 四个叠加元素（已全部接入真实数据源）

新增 `src/overlay.c` —— 统一产出状态数据，绘制层只负责画。每项都有降级方案，**断网/无 ADC 时界面不会崩**。

### ① 顶部状态（时间 / Wi-Fi / 电量）

| 元素 | 真实来源 | 降级方案 |
|---|---|---|
| 时间 | SNTP 同步到 RTC | 未连网时用 menuconfig 初始时间 + 运行时钟，每分钟 +1；未校时时左侧点一个提示点 |
| Wi-Fi | `esp_wifi_sta_get_ap_info()` 的 RSSI | 事件驱动：≥-55dBm 满格 3、≥-68 为 2、其余 1；断开则弧线暗到 20% |
| 电量 | ADC1 分压采样（可选） | 关闭 ADC 时用模拟值缓慢下降；≤15% 时填充块闪烁提示 |

**时间用 3×5 点阵数字手绘，零字体依赖** —— 不占 CJK 字库的 flash，机械感和机器人脸也统一。

### ② 底部声波（22 根条）

由 I2S 的 RMS 派生 **8 段包络**，再线性插值到 22 根条。
低频段慢（释放系数 0.06）、高频段快（0.30），配合增益补偿，视觉上接近真实频谱，但**不做 FFT，算力几乎为零**。

> ⚠️ 抖动必须用「秒」为单位。我第一版误用毫秒，抖动快到变成了噪点闪烁 —— 已修正。

### ③ 自动眨眼

随机间隔 1.5–3.5s。眨眼不是纯垂直压扁，而是**横向同时拉伸 12%**（squash & stretch），睁到底过冲 6% 再回弹。

### ④ 呼吸缩放

待机时眼睛 ±3.5% 缓慢起伏，1.7s 一个周期。避免静止时像"死机"。

### 运行时开关

| 操作 | 效果 |
|---|---|
| VOL+ 长按 | 顶部状态 开/关 |
| 双 VOL 同按 | 底部声波 开/关 |

`emopet_set_auto_blink()` / `emopet_set_breathe()` 也有接口，按需在代码里改。

## 7. 怎么加新表情

在 `emopet_face.c` 的表情表 `EMO[]` 里加一行，同时在 `app_config.h` 的 `emo_id_t` 加一个 ID：

```c
[EMO_CONFUSED] = { EM_DOT, 44, 48, 0.0f, 1.0f, 0, 0.35f, 0, 0 },
```

要左右眼不同（比如 wink），在 `R_OVER[]` 里加覆盖：

```c
[EMO_CONFUSED] = { true, { EM_ARC, 44, 16, 1.0f, 1.0f, 0, 0.0f, 0, 0 } },
```

改完先在 `docs/emopet_face_preview.html` 的 `EMOTIONS` 里同步改，确认观感再烧。

预览页有 **「可爱版 / 原版」** 对比开关，可以直观看出高光点和幼态布局带来的差异。

### 还想更可爱？

- 把 `EMO[EMO_IDLE]` 的 `w/h` 再放大到 58/66（眼睛越大越幼态，但别超过 70 否则显拥挤）
- 给待机加一个**每隔几秒的「wink」**（随机单眨眼），比随机双眨眼更俏皮
- 说话时让高光点轻微上下浮动 ±2px，眼睛会显得更有神

## 8. 首次编译若报错，优先看这 3 处

（与 `esp32_pet_chat` 工程相同的 v6.1 适配点）

1. **`esp_lcd_panel_dev_config_t` 的色格式字段**（`display.c`）
   v6.1 用 `.color_format = LCD_COLOR_FORMAT_RGB565` 取代 `.bits_per_pixel = 16`。
   若报字段名不存在，查 `$IDF_PATH/components/esp_lcd/include/esp_lcd_panel_dev.h`。

2. **LVGL canvas 的 buffer 参数**（`emopet_face.c`）
   LVGL 9 用 `LV_COLOR_FORMAT_RGB565`；锁到 LVGL 8 的话改回 `LV_IMG_CF_TRUE_COLOR`（代码里已有版本宏）。

3. **本工程不需要 CJK 字体**（时间用手绘点阵），但如果 `sdkconfig.defaults` 里的
   `CONFIG_LV_FONT_SIMSUN_16_CJK` 在你的 IDF 里不存在，把它删掉即可。

4. **overlay 依赖的组件**：`esp_wifi` / `esp_netif` / `esp_sntp` 已在 `main/CMakeLists.txt` 的
   `REQUIRES` 里列出。若你还没接 Wi-Fi，需先在 menuconfig 里启用 Wi-Fi，或把
   `CONFIG_EMOPET_SNTP_ENABLE` 关掉。

v6.x **默认"警告即错误"**，本工程已在 `main/CMakeLists.txt` 加 `-Wno-unused-parameter` 兜底。
