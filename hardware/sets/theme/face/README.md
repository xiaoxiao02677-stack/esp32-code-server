# 极简脸 face · Square Face 主题（双发光眼 + 嘴，纯脸零文字）

> 一张会呼吸的脸，不多一个字。
> 240×240 黑底，两只发光的眼睛，一只会说话的嘴——
> 对话内容全靠语音，脸只负责表情。

先打开 `docs/face_ui_preview.html` 看高保真原稿（Square Face · Minimal，
240×240 浏览器仿真，8 表情切换 + 眨眼/呼吸/游荡/说话拟态全动效可试）。

本主题已集成进 sets 构建链：

```bash
cd hardware/sets
python build.py --board yh-cam --theme face          # 单板单主题
python build.py --all                                # 全矩阵（含 face）
```

四板全适配：`yh-cam`（320×240 横/240×320 竖，NVS `lcd_mode` 切换）、
`yh-big-ili9341`（320×240 横）、`yh-154tft-wifi` / `yh-n16r8-st7789`
（240 圆屏）。

## 1. 设计要点（与 HTML 原稿逐项对齐）

| 要点 | 说明 |
|---|---|
| **纯脸零文字** | 脸上不落一字，无字体依赖；对话内容全靠语音传达，气泡/时间/电量/提示全部隐藏。系统卡片（配网/激活码/升级）例外保留——那是功能界面，不是脸 |
| **状态辉光** | 眼睛辉光色随设备态变化（独立于表情的第二通道）：待机=原稿淡蓝 / 聆听=青绿 / 说话=暖橙 / 联网=琥珀慢闪 / 致命错误=珊瑚红——零文字下按 BOOT 后不用猜状态 |
| **三层辉光眼** | 每只眼 3 层同心圆（辉光外圈 d×1.22 @20% / 内圈 d×1.10 @40% / 主体 d 不透明 #E8F4F6）——box-shadow 双层辉光的 LVGL 等效方案，硬边分层即风格（RGB565 纪律，同 dengyu 光萤） |
| **8 态表情** | 待机/说话/开心/害羞/思考/困倦/惊讶/生气，眼缩放（happy +8% / sleepy -12% / surprise +18%…）+ 嘴四参数（宽/高/圆角/纵移）连续过渡，lerp 8%/帧 |
| **眨眼** | 160ms cos 缓动压扁 scaleY（三层同比 squash，辉光跟着压），平均 ~4.8s 一次 |
| **呼吸** | 全局 ±2.5%（idle 1.1s / sleepy 1.6s 更缓），乘进眼径与嘴高 |
| **眼神游荡** | idle 态小概率重选目标点 ±4px（30fps 换算后平均 ~2.8s 一次），lerp 5%/帧跟随 |
| **说话拟态** | 点头 ±1.8px（180ms 周期）+ 嘴开合 90ms 周期 10px 幅度正弦（定时器拟态，非真实音频能量） |
| **傲娇回弹** | 双击 BOOT：520ms 正弦 0→+16%→0 回弹 + 随机小表情（开心/害羞/惊讶三选一）1.8s，回 idle |
| **状态机真源** | `Application::GetDeviceState()` 250ms 轮询对账（dengyu/pet 同款先例）；说话中情绪只记不切，TTS 结束自然回落形成「说完还在笑」余韵 |
| **帧预算** | 单 lv_timer 33ms ≈ 30fps，说话态隔帧降 15fps 给音频/网络任务让预算（20MHz SPI 全屏 flush 一帧 60ms） |

## 2. 状态信号对照表（按 BOOT 后看眼睛辉光就知道在干嘛）

| 设备状态 | 眼睛辉光 | 脸部动作 |
|---|---|---|
| 待机 idle | 淡蓝 #B4DCFF（原稿色） | 呼吸 + 眼神游荡 + 眨眼 |
| 聆听 listening | **青绿 #7BE8A0** | 微笑注视（游荡停） |
| 说话 speaking | **暖橙 #F7B96A** | 点头 ±1.8px + 嘴 90ms 开合 |
| 联网/升级 connecting | **琥珀 #F7D96A 慢闪**（1.6s 周期） | 一字嘴思考 |
| 致命错误 fatal | **珊瑚红 #F76E5E** | 方嘴生气 |

## 4. 源码位置

```
yuhe-esp32/main/display/face_skin/
├── face_skin_types.h      # 表情/几何/动效类型 + 配色宏
├── face_core.h/.c         # 纯 C 渲染循环（眨眼/呼吸/游荡/嘴动/回弹，
│                          #   30fps 显式状态机，不用 lv_anim）
└── face_skin_display.h/.cc  # 主类（继承 YhSkinDisplay 骨架 + 250ms 设备态对账）
```

接线点（与 pixel-pet/emopet/dengyu 完全同构）：
- `main/Kconfig.projbuild`：`choice YH_UI_THEME` 的 `YH_UI_THEME_FACE`
- `main/CMakeLists.txt`：条件编入 + `BOARD_TYPE` 追加 `-face` 后缀
  （OTA 轨道隔离，`out/<id>-face/` 产物目录一致）
- 四板 `yh_set_*.cc` / `yh_set_lcd_display.h`：`#elif CONFIG_YH_UI_THEME_FACE`
  分支（构造签名与 YhSkinDisplay 完全一致，只换类名）
- `build.py`：`THEMES["face"]` + `theme_keys` 剔除集

## 5. 交互

| 操作 | 反馈 |
|---|---|
| 短按 BOOT | 进入聆听（微笑注视预置，轮询随后接管） |
| 双击 BOOT | 傲娇回弹 520ms + 随机小表情 1.8s（开心/害羞/惊讶） |
| 长按 BOOT | 静音状态落到脸上（静音=困倦蔫脸 / 开声=笑脸）；聆听中=眨眼示意 |

## 6. 屏型适配（face_geom_make 按短边等比换算）

| 屏型 | 布局 |
|---|---|
| 240×240 圆屏/方屏 | 原稿坐标原样（眼/嘴全部落在内切圆内，无需收缩） |
| 320×240 横屏 | 眼距拉开（中心距基准 56→78px），脸横向居中 |
| 240×320 竖屏 | 原稿坐标原样（脸占 y 47~169，底部自然留白 ~150px） |

## 7. 与其他主题的取舍对比

| 维度 | face | dengyu | pixel-pet |
|---|---|---|---|
| 文字 | **零**（纯脸） | 剧场字幕流 | 气泡 |
| 字体依赖 | **无** | 专属字档 24KB + 主题字体 | 主题字体 |
| 表情通道 | 眼缩放+嘴形 | 光萤配色+状态短语 | 五态宠物图 |
| 说话反馈 | 点头+嘴拟态 | EQ 声纹 | 嘴部能量拟态 |
| 双击彩蛋 | 傲娇回弹 | 配色轮换(NVS) | 换宠 |
