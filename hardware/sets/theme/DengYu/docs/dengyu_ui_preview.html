灯语 Lumen —— 一盏会说话的灯

为无触摸屏的 ESP32 陪聊设备设计的界面提案。屏幕不是对话工具，而是「她的存在本身」： 顶部一颗呼吸的光萤承载情绪，下方剧场字幕流承载语言。整套视觉在 RGB565 16bit 色深下逐色校准。

01 / CONCEPT创意概念

情绪关键词：暖夜 · 呼吸 · 留白 · 剧场。 它不像默认聊天软件的地方在于——聊天软件把对话做成左右分列的气泡战线，而灯语把屏幕做成一盏灯和一个舞台： 你说话时她在听（光变青），她说话时字幕逐字浮现，沉默时她依然亮着、在想你。

P1

存在优先于信息

任何时刻屏幕上必有一颗活着的光。信息可以没有，陪伴感不能断——待机不是黑屏，是「想着你」。

P2

一个时刻只说一件事

聆听、思考、说话、休息四种状态互斥呈现，绝不同屏堆叠。320px 高度里出现两个视觉焦点就是失败。

P3

暖色是她的体温

深夜墨蓝底 + 炭火橙光，唯一强调色系。青苔绿只属于「聆听」，珊瑚红只属于「异常」，绝不通用。

02 / LIVE RENDER真机渲染模拟 · 六状态

左栏切换设备状态。屏幕中所有颜色均为 RGB565 量化后的实际显示色；所有动效均可映射到 LVGL v9 lv_anim，映射路径与实现成本见左栏说明。

16bit 渐变策略：全案不做连续渐变面。光萤的「辉光感」由 3 层同心圆（opaque #FFEBC5 → #FFCA8C → #C57E3A）叠半透明边圈构成，RGB565 下每层都是精确颜色、零 banding；需要更柔的过渡时用 4 层而非渐变。半透明叠加全部限制在 ≤2 层，叠加后色值经预算：例如 ember300@opa180 落在 ink200 上 ≈ #C9A97C，仍在安全可读区。

04 / LVGL PATH关键效果落地路径

以下 API 均已在 LVGL v9 官方文档核对；v8.4 差异单独标注。片段为示意骨架，非完整工程代码。

① 光萤呼吸 + 涟漪（存在感的全部）

光萤 = 3 层 lv_obj 圆形（radius = 宽度一半）叠同心圆，不用渐变；涟漪 = 独立圆环对象（border 1.5px、背景透明），动画驱动 size 与 opa。 呼吸用 zoom 而非宽高，避免每帧 relayout，只触发重绘。 

/* LVGL v9 —— 呼吸：zoom 256→322，opacity 209→255 */
static void breathe_anim(lv_obj_t *core) {
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, core);
    lv_anim_set_exec_cb(&a, (lv_anim_exec_xcb_t)lv_obj_set_style_transform_zoom);
    lv_anim_set_values(&a, 256, 322);
    lv_anim_set_duration(&a, 2400);            /* 半周期 2.4s */
    lv_anim_set_reverse_duration(&a, 2400);    /* 来回 = 4.8s 呼吸 */
    lv_anim_set_repeat_count(&a, LV_ANIM_REPEAT_INFINITE);
    lv_anim_set_path_cb(&a, lv_anim_path_ease_in_out);
    lv_anim_start(&a);
}
/* 涟漪：size 50→178 + opa 140→0，双道用 lv_anim_set_delay 错相 3200ms */

成本：重绘区域以光萤为中心约 178×178px（屏 34%），但呼吸/涟漪都是慢动画，LVGL 按脏区刷新，实测类效果在 30fps 内稳定。低配档涟漪减为单道 9s。

② 字幕流式逐字（她的「开口说话」）

核心：一个 lv_label 持有一整句，文本到达时用 lv_label_ins_text 按字符索引追加（LV_LABEL_POS_LAST），配 90–140ms 定时节流。 绝不每 token 建新 label、绝不每帧刷新——label 只在追加时 invalidate 自身行区域。光标是 label 尾部一个 7×15px 小对象，1s 步进闪烁。 

/* LVGL v9 —— 流式追加（在 lv_timer 回调里，120ms/字） */
lv_label_ins_text(subtitle, LV_LABEL_POS_LAST, chunk);  /* 按字符索引，非字节 */
lv_obj_scroll_to_y(flow, LV_COORD_MAX, LV_ANIM_OFF);    /* 行满后顺手上滚 */

成本：每次追加仅刷新 label 行区域（约 200×23px），120ms 一次完全无压力。这是全案唯一「高频」操作，也是最便宜的一个。

③ 复合入场时间线（v9 专属，v8 需手搓）

字幕入场 = y 位移 + opa + 微缩放三线并发。lv_anim_timeline 是 v9 新增（v8.4 无此 API，需用多个 lv_anim_set_delay 手动编排），支持 set_reverse / set_progress——进度可 scrub，意味着「入场动画」可被倒放成「退场」。 

/* LVGL v9 —— 字幕入场时间线：340ms ease-out */
lv_anim_timeline_t *tl = lv_anim_timeline_create();
lv_anim_timeline_add(tl, 0,   &anim_y);     /* y +10 -> 0   */
lv_anim_timeline_add(tl, 0,   &anim_opa);   /* 0 -> 255     */
lv_anim_timeline_add(tl, 40,  &anim_zoom);  /* 245 -> 256   */
lv_anim_timeline_start(tl);                 /* 总时长 340ms */

红线自查：本方案零实时模糊、零大面积半透明叠层、零每帧重建对象。唯一接近边界的操作是 EQ 五段 bar 高度动画——已标注低配降级为 3 根。
