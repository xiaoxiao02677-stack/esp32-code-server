# ESP32-S3-N16R8 硬件

## 主控信息

| 项目     | 参数                                          |
| -------- | --------------------------------------------- |
| MCU      | ESP32-S3                                      |
| 型号     | ESP32-S3-N16R8                                |
| Flash    | 16 MB                                         |
| PSRAM    | 8 MB                                          |
| 框架     | ESP-IDF 6.0.1                                 |
| 语言     | C                                             |
| 开发环境 | VS Code + ESP-IDF 插件                        |
| 开发方式 | ESP-IDF Native                                |
| 本地编译 | `D:\INSTALL\esp-idf-v6.0.1\esp-idf命令行.bat` |

## 外设连接

### 1. ST7789 LCD（240×240 SPI 显示，主屏）

| LCD  | GPIO |
| :--: | :--: |
| SCL  |  21  |
| SDA  |  47  |
| RST  |  45  |
|  DC  |  40  |
|  CS  |  41  |
|  BL  |  42  |

### 1.1 备用屏 SSD1306 OLED（128×64 I2C，可选）

使用独立引脚（与主屏互不影响），只需再接两根电源线。固件开机自动探测 I2C 地址 0x3C：探测到即用备用屏，探测不到（未接）则自动走主屏方案，无需改代码或重烧固件。

| 备用屏 | GPIO / 电源 |
| :--: | :--: |
| SCL  |  9   |
| SDA  |  8   |
| VCC  | 3V3  |
| GND  | GND  |

### 2. MAX98357A 功放（I2S 输出）

| 功放 | GPIO / 电源 |
| :--: | :---------: |
| LRC  |     16      |
| BCLK |     15      |
| DIN  |      7      |
| GAIN |     GND     |
|  SD  |    3.3V     |
| VIN  |    3.3V     |

### 3. INMP441 麦克风（I2S 输入）

| 麦克风 |  GPIO / 电源  |
| :----: | :-----------: |
|  SCK   |       5       |
|   WS   |       4       |
|   SD   |       6       |
|  VDD   |     3.3V      |
|  L/R   | GND（左声道） |
